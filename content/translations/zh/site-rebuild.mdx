这个网站正在重建，希望成为长期记录技术实践的地方。

以前的博客依赖 Vue 应用、独立后端和数据库。新版本把文章作为 MDX 文件保存在 Git 中，并通过 GitHub Pages 发布静态网站。

## 原则

- 用 Markdown 或 MDX 写文章，并纳入版本控制。
- 无需租用服务器、数据库、账号系统或私有发布后台。
- 区分整理完善的文章和持续更新的学习笔记。
- 项目记录以证据为依据，明确说明已知限制。

第一批旧文章会在原数据库备份或缓存副本恢复后导入。
