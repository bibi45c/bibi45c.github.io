Redis 适合短期缓存、限流计数、会话或队列等场景。缓存项必须带 TTL、命名空间和明确的失效方式。

```python
key = f"product:{product_id}:summary"
cache.set(key, payload, timeout=300)
```

权威数据仍在数据库或专用存储中。不要把密码、令牌或未加密个人数据放进共享缓存，也不要假设缓存一定存在。
