This site is being rebuilt as a durable place to write about practical technical work.

The previous blog relied on a Vue application, a separate backend, and a database. The new version keeps its articles in Git as MDX files and publishes a static site through GitHub Pages.

## Principles

- Write in Markdown or MDX and keep every article version controlled.
- Avoid a rented server, database, account system, and private publishing backend.
- Separate polished articles from evolving learning notes.
- Keep project write-ups evidence-based and explicit about known limitations.

The first imported legacy articles will be added once their original database backup or cached copies are recovered.
