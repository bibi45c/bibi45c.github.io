旧 Notebook 扩展教程容易随 JupyterLab 版本失效。比起依赖某个插件，更重要的是让笔记本在干净环境中从上到下运行。

- 将依赖写入 lock file 或环境文件。
- 记录输入数据的位置、版本与字段含义。
- 重启内核后执行全部单元，避免隐藏状态。
- 将可复用逻辑提取到普通 Python 模块并测试。

Notebook 适合探索和说明；长期生产任务应放进可测试、可调度的代码仓库。
