将 users、orders、admin 等路由拆进 Blueprint，能让路由、错误处理和测试更容易定位。

```python
api = Blueprint("api", __name__)

@api.get("/projects")
def list_projects():
    return {"items": []}
```

应用通过 `register_blueprint(api, url_prefix="/api")` 挂载模块。不要因为路由位于 `admin` Blueprint 就默认它安全；认证和授权仍要在服务端逐请求检查。
