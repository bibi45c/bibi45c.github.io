`ENTRYPOINT` 定义容器默认执行的程序，`CMD` 提供默认参数。两者配合时使用 JSON exec form。

```dockerfile
ENTRYPOINT ["python", "-m", "http.server"]
CMD ["8000"]
```

运行时传入参数可覆盖 `CMD`。不要因为 shell form 写起来短就使用它：额外 shell 会改变参数展开和终止信号传递行为。
