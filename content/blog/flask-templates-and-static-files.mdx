模板文件放在 `templates`，静态资源放在 `static`，由应用或前置 CDN 提供。将用户输入输出到 HTML 时保持默认转义，不要为了方便关闭自动转义。

生产环境的静态文件通常由反向代理或对象存储/CDN 托管。构建产物的缓存策略应带版本号，避免用户长期拿到旧的 CSS 或 JavaScript。
