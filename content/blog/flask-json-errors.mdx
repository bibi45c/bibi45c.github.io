API 应返回 JSON 和正确 HTTP 状态码，而不是把错误堆栈或数据库信息暴露给客户端。

```python
@app.errorhandler(NotFoundError)
def handle_not_found(error):
    return {"error": "not_found", "message": "Resource not found"}, 404
```

400 表示输入无效，401 表示未认证，403 表示已认证但无权限，404 不应帮助攻击者枚举敏感资源。未处理异常记录到受控日志，客户端只得到通用 500 响应。
